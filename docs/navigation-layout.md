# Navigation layout decision

T4 keeps all six primary tabs visible.

At widths up to 360 dp, Tamil and English tab labels use an 8.5 sp centred label style, may wrap to at most two lines, and are never ellipsised. At larger widths the tab label is 10.5 sp. The exact Tamil labels are: முகப்பு, கற்க, மூத்தோர், வகுப்பு, ஊர்சபை, கணிப்பு.

The six prototype SVG-derived ImageVectors already present at the Phase 0 checkpoint are retained. Latin letter marks are not used.
